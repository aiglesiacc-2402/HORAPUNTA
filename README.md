## Instrucciones para utilizar correctamente Github
1. git pull nada más entrar
2. git add "nombre del fichero para hacer el commit posteriormente" // También podemos hacer git add . y agregamos todo
3. git commit -m "DESCRIPCION DEL COMMIT" tras hacer cambios
4. git push

>[!NOTE] IMPORTANTE
> Los pasos 2 y 3 se pueden mezclar haciendo git commit -am "DESCRIPCION". Equivale a hacr un git add . y luego el commit
